# Weather App 🌤️

A responsive weather application built with Next.js, React, and Tailwind CSS.

## Features

- Search for cities and view weather information.
- Display current temperature and weather conditions.
- Switch between Celsius and Fahrenheit.
- View humidity, wind speed, and atmospheric pressure.
- Explore sunrise, sunset, and air quality information.
- Responsive design for desktop, tablet, and mobile.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Axios
- Open-Meteo API
- Lucide React
