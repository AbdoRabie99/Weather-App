# 🌤️ Weather App

A modern, responsive weather application built with **Next.js**, **React**, and **Tailwind CSS**, powered by the **Open-Meteo API**. Search for cities, explore current weather conditions, and view additional weather and air quality information through a clean, user-friendly interface.

## 🚀 Live Demo

**[View Weather App](https://weather-app-abdo-rabie.vercel.app/)**

## ✨ Features

- 🔍 **City Search:** Search for cities and retrieve their weather information.
- 🌡️ **Temperature Conversion:** Switch between Celsius (°C) and Fahrenheit (°F).
- 💨 **Current Weather:** View temperature, feels-like temperature, humidity, wind speed, and atmospheric pressure.
- 📅 **Weather Forecast:** Explore upcoming weather conditions and daily forecasts.
- 🌅 **Sunrise & Sunset:** View sunrise, sunset, and daylight duration.
- 🌫️ **Air Quality:** Check the Air Quality Index (US AQI), PM2.5, and PM10 levels.
- 📱 **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- ⚡ **Real-Time Data:** Retrieve weather information using the Open-Meteo API.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Library:** React
- **Language:** JavaScript (JSX)
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **Weather & Air Quality Data:** Open-Meteo API
- **Icons:** Lucide React
- **Deployment:** Vercel
